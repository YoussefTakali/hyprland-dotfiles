# Select and right-click paste

Kitty now automatically copies selected text to the clipboard. A plain right-click pastes the primary selection. This applies to the terminal; other applications retain their context menus. Terminal programs that capture mouse input keep their own mouse handling.

Open a new terminal or press Ctrl+Shift+F5 to reload an existing one.

Backups: `~/.local/state/mouse-paste-backups/`.
