# Login theme catalogue

**Super+Ctrl+Alt+L** opens the login theme chooser when SDDM Astronaut is installed.
Enter applies a preset after administrator authentication. Shift+Enter previews it.

The default Jake preset can use the video and poster from the installed Astronaut
theme. Optional personal media can be placed in this directory using the
filenames in `catalog.json`. Run the installer to copy them to the local
catalogue. The chooser lists only presets whose poster and video are available.
Optional desktop wallpapers can be placed under `wallpapers/Itachi-4K/` and
selected with **Super+W**. Personal PNG and MP4 files are excluded from Git.
